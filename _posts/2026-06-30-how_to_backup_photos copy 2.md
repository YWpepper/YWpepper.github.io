这篇博客介绍了在 macOS 上通过 WebCatalog 安装并使用粉笔软件的方法。

<!-- more -->

## 1. 什么是粉笔软件

粉笔软件是一款可以把网页版工具打包成桌面应用的客户端。通过 WebCatalog，我们可以把粉笔的 Web 版安装到 Mac 上，获得更原生的体验。

## 2. 使用前准备

- macOS 系统，建议 10.15 及以上版本
- 已安装 WebCatalog
- 需要粉笔账号（如有）
  ![](https://virginia-pepper.oss-cn-guangzhou.aliyuncs.com/img/blog/202607251115976.png)

## 3. 安装步骤

1. 打开 WebCatalog。
2. 在搜索框中输入“粉笔”或“Chalk”。
   ![](https://virginia-pepper.oss-cn-guangzhou.aliyuncs.com/img/blog/202607251118340.png)
3. 选择对应的粉笔应用并点击“Install”进行安装。
4. 安装完成后，WebCatalog 会将粉笔作为一个独立应用添加到 Mac 中。

## 4. 启动与登录

- 通过 Launchpad 或 WebCatalog 中启动粉笔应用。
- 使用你的粉笔账号登录。
- 如果是第一次使用，可能需要授权摄像头、麦克风或通知权限，按需允许即可。

## 5. 常见使用场景

- 进行在线课堂、远程教学时，直接在桌面应用中打开即可。
- 编辑或书写内容时，桌面应用比浏览器更稳定。
- 可以将常用页面固定到 WebCatalog，快速打开。

## 6. 小贴士

- 如果 WebCatalog 中没有找到“粉笔”，可以先打开粉笔网页版，然后使用 WebCatalog 的“Create App”功能手动创建。
- 安装完成后，记得将粉笔应用固定到 Dock，日后使用更方便。
- 若遇到显示异常，可尝试在 WebCatalog 中重新安装或更新应用。

## 7. 结语

通过 WebCatalog 在 Mac 上安装粉笔软件，可以把 Web 工具变成桌面应用，使用更加方便，也更接近本机体验。

使用 WebCatalog 下载对应的粉笔软件，安装后可以在 Mac 上使用。
